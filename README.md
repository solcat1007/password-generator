# 密码生成器 (Password Generator)

安全密码生成工具网页版，带有 Canvas 动态背景和密码强度可视化。

## 功能

- **加密随机**：使用 `crypto.getRandomValues()` 生成强密码
- **四种字符集**：大写字母、小写字母、数字、特殊符号，自由组合
- **长度调节**：滑块 + 数字输入框双重控制，范围 4-64 位
- **强度可视化**：实时颜色渐变进度条显示密码强度
- **一键复制**：点击复制按钮复制密码
- **Canvas 背景**：动态网格背景装饰
- **中英文切换**：界面支持中文/英文
- **全屏模式**：点击"开始"进入全屏

## 使用方法

1. 用浏览器打开 `index.html`
2. 勾选/取消需要的字符类型
3. 拖动滑块或输入数字调整密码长度
4. 自动生成密码显示在输入框中
5. 点击"复制"按钮复制密码

## 安全说明

- 密码在浏览器本地生成，不上传服务器
- 使用 Web Crypto API 确保随机性
- 不保存生成的密码

## 技术栈

纯 HTML/CSS/JavaScript，Web Crypto API + Canvas。
