# 密码生成器 (Password Generator) v2.0

高强度随机密码生成工具，全部在本地完成，不上传任何数据。

## 🆕 v2.0 更新

- 新增 **强度环形图**：SVG 风格锥形渐变圆环，实时显示评级与熵值
- 新增 **批量生成**：一次生成 1–12 条密码，点击任意一条即可复制
- 新增 **自定义字符排除**：输入不想出现的字符，密码池自动过滤
- 新增 **生成历史**：最近 24 条记录本地保存，点击即可复用
- 随机算法升级为 **拒绝采样**，消除取模偏差，字符分布更均匀
- 注入 SOLCAT 彩蛋引擎，UI 全面美化

## 功能

- **密码学安全随机**：使用 `crypto.getRandomValues()`
- **四种字符集**：小写、大写、数字、符号自由组合（至少保留一种）
- **长度调节**：滑块 6–64 位，实时显示长度与熵值
- **强度评估**：弱 / 中 / 强 / 极强 四档，环形图 + 色彩反馈
- **排除字符**：如排除 `0O1lI|`，避免混淆
- **一键复制**：点击密码或复制按钮即可写入剪贴板

## 使用方法

1. 打开 `index.html`
2. 勾选字符集，拖动滑块设置长度与批量数量
3. 必要时填写「排除字符」
4. 点「生成」或「批量生成」，点击结果即可复制
